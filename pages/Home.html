One Grammar. One Program. One Compiler.

Instead of introducing a different language in every chapter, every example throughout this website uses the same grammar and the same running example. As you progress through the chapters, you will watch this single program evolve from raw characters into a fully compiled program. 

main() {
  number x := 5;
  text   y := "hello";
  number z := x + y;   /* adding a number to text — should this work? */
}

This is the only program we are working with throughout. Every compiler phase studies this same program from a different perspective. Also, follow the unified grammar here
